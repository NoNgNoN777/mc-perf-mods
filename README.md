# mc-perf-mods · ลงม็อดเพิ่มความลื่นให้ Minecraft

โปรแกรมช่วยลงม็อดที่ทำให้เกมลื่นขึ้น พร้อม Essential สำหรับเล่นกับเพื่อน ลงให้ม็อดแพ็กที่มีอยู่ได้ในไม่กี่คลิก

- **เลือกไฟล์ให้เอง** ตรงกับเวอร์ชันเกมและ loader (Forge · NeoForge · Fabric · Quilt) ไม่ต้องไล่หาทีละตัว
- **ไม่แตะม็อดเดิม** ลงเพิ่มอย่างเดียว ม็อดที่มีอยู่แล้วหรือมีตัวที่ทำหน้าที่เดียวกันจะข้ามให้
- **กันม็อดชนกัน** เช็คให้ก่อนว่าม็อดไหนใช้ร่วมกันไม่ได้
- **ย้อนกลับได้เสมอ** ลงแล้วเกมมีปัญหา กดเอาออกได้ทันที
- **บอกว่าเพื่อนต้องลงอะไรตาม** เวลาเล่นด้วยกันผ่าน Essential

ไฟล์ม็อดทั้งหมดโหลดจาก [Modrinth](https://modrinth.com) และเช็คความถูกต้องของไฟล์ทุกครั้งก่อนลง

> ไม่ใช่โปรแกรมทางการของ Minecraft · NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

ให้กด **More info** แล้วกด **Run anyway** ทำแค่ครั้งแรกครั้งเดียว

## วิธีใช้

1. **ปิดเกมก่อน**
2. ดับเบิลคลิก **`MC-Perf-Mods.exe`**
   หรือลากโฟลเดอร์ม็อดแพ็กมาวางบน `MC-Perf-Mods.exe` โปรแกรมจะตรวจให้ทันที
3. กด **เลือกโฟลเดอร์** แล้วเลือกโฟลเดอร์ของม็อดแพ็ก (ดูวิธีหาได้ด้านล่าง) จากนั้นกด **ตรวจม็อดแพ็ก**
4. เลือกม็อดที่ต้องการ
   - **ชุดเพิ่มความลื่น + Essential** เลือกไว้ให้แล้ว ไม่อยากได้ตัวไหนก็กดเอาออกได้
   - **ม็อดสามัญประจำบ้าน** ม็อดยอดนิยมที่ช่วยให้เล่นสะดวกขึ้น เช่น JEI, แผนที่, Voice Chat ยังไม่ได้เลือกไว้ เลือกเพิ่มได้ตามชอบ
   - คลิกตรงไหนของแถวก็เลือกได้ และคลิกที่หัวข้อเพื่อหุบหรือกางแต่ละหมวด
   - ช่อง **ค้นหา** ใช้หาม็อดจากชื่อหรือคำอธิบาย พิมพ์ภาษาไทยได้ เช่น "แผนที่"
5. กด **ติดตั้งที่เลือกไว้** เสร็จแล้วเปิดเกมได้เลย

ถ้าลงแล้วเกมมีปัญหา กด **ย้อนการติดตั้ง** แล้วเลือกรายการตามวันและเวลาที่ลง
โปรแกรมจะลบเฉพาะไฟล์ที่ตัวเองลงไว้ ม็อดอื่นในแพ็กไม่ถูกแตะ

### ไม่ต้องกลัวลงไม่ครบ

- เลือกม็อดที่ต้องใช้ม็อดอื่นคู่ด้วย โปรแกรมจะเลือกตัวที่ต้องใช้ให้อัตโนมัติ
- จะเอาม็อดที่ตัวอื่นยังต้องใช้ออก โปรแกรมจะถามก่อนทุกครั้ง
- ใต้ชื่อม็อดบอกไว้ว่าต้องใช้คู่กับอะไร ถ้าขาดตัวไหนจะขึ้นเป็นสีแดง

### หาโฟลเดอร์ม็อดแพ็กได้ที่ไหน

โฟลเดอร์ที่ถูกต้องคือโฟลเดอร์ที่มีโฟลเดอร์ `mods` อยู่ข้างใน

- **CurseForge:** คลิกขวาที่ม็อดแพ็ก แล้วเลือก **Open Folder**
  ปกติจะอยู่ที่ `C:\Users\ชื่อผู้ใช้\curseforge\minecraft\Instances\ชื่อม็อดแพ็ก`
- **Prism Launcher:** คลิกขวาที่ม็อดแพ็ก แล้วเลือก **Folder**

## เล่นกับเพื่อนผ่าน Essential

1. ทุกคนต้องใช้ **ม็อดแพ็กเดียวกัน** และมี **Essential** ทุกคน
2. เข้าเกมครั้งแรกจะมีหน้าล็อกอินของ Essential ให้ล็อกอินให้เรียบร้อย
3. คนหนึ่งเปิดโลก แล้วกด **Invite** เพื่อชวนเพื่อนจากเมนูของ Essential
   ไม่ต้องเช่าเซิร์ฟเวอร์ และไม่ต้องตั้งค่าเปิดพอร์ต

### เพื่อนต้องลงม็อดไหนตามบ้าง

หลังชื่อม็อดแต่ละตัวมีป้ายบอกไว้ ชี้เมาส์ค้างไว้ที่ป้ายจะมีคำอธิบายเพิ่ม

| ป้าย | ทำงานฝั่งไหน | เพื่อนต้องลงไหม |
|---|---|---|
| 🩷 **ทุกคนต้องลง** | client + server | **ต้องลง** ทั้งคนเปิดโลกและเพื่อน |
| 🧡 **เฉพาะคนเปิดโลก** | server | ไม่ต้อง ลงแค่เครื่องคนเปิดโลกก็พอ |
| 💚 **เฉพาะเครื่องตัวเอง** | client | ไม่ต้อง ช่วยเฉพาะเครื่องที่ลงไว้ |
| 💚 **ลงฝั่งเดียวก็ได้** | client หรือ server | ไม่ต้อง ทำงานได้แม้มีแค่บางคนที่ลง |

ม็อดที่ทุกคนต้องลงมีแค่ไม่กี่ตัว คือ **Essential**, **Simple Voice Chat** และ **Ping Wheel**
ม็อดเพิ่มความลื่นทั้งหมดเป็นแบบ "เฉพาะเครื่องตัวเอง" เพื่อนจะลงตามหรือไม่ก็ได้

ถ้าไม่อยากไล่ดูทีละตัว กดปุ่ม **เพื่อนต้องลงตาม … ม็อด** ที่แถบล่าง โปรแกรมจะสรุปให้ ส่งรายการนั้นให้เพื่อนได้เลย

> ข้อมูลฝั่ง client/server มาจากที่ผู้ทำม็อดระบุไว้บน Modrinth
> แต่ Essential กับ Simple Voice Chat ระบุไว้ไม่ตรงกับการเล่นผ่าน Essential โปรแกรมจึงปรับให้เป็น "ทุกคนต้องลง"

## โปรแกรมกันม็อดชนกันยังไง

- **มีอยู่แล้วไม่ลงซ้ำ** รวมถึงม็อดที่ทำหน้าที่เดียวกัน เช่น
  Sodium / Embeddium / Rubidium · Iris / Oculus · Lithium / Canary / Radium · JEI / REI / EMI ·
  Jade / WTHIT / HWYLA · Xaero / JourneyMap / VoxelMap · ม็อดแสงไฟรอบตัวทุกตัว ·
  Zoomify / Ok Zoomer · Simple Voice Chat / Plasmo Voice · Mod Menu / Catalogue
- **เช็คกับข้อมูลของผู้ทำม็อด** โปรแกรมดูว่าม็อดในแพ็กคือตัวไหนบน Modrinth แล้วเช็ครายการ "ใช้ร่วมกันไม่ได้" ที่ผู้ทำม็อดประกาศไว้
  ทั้งระหว่างม็อดใหม่กับม็อดเดิม และระหว่างม็อดใหม่ด้วยกันเอง
- **Indium** ใช้กับ Sodium รุ่นใหม่ (เกม 1.21 ขึ้นไป) ไม่ได้ จึงเสนอให้เฉพาะเกม 1.20.x ลงไป
- **บน Forge/NeoForge** ไม่ลงม็อดที่ต้องพึ่ง Sinytra Connector (ตัวรันม็อด Fabric บน Forge) เพราะยังเป็นรุ่นทดลอง
- **เจอ OptiFine** จะไม่ลงม็อดด้านกราฟิกและ shader เพราะใช้ร่วมกันไม่ได้
- **ม็อดที่ลงไม่ได้** ม็อดอื่นที่ต้องใช้มันก็จะไม่ถูกลงไปด้วย
- **ไม่ใส่ C2ME และ Distant Horizons** ไว้ในชุด เพราะมักมีปัญหากับม็อดแพ็กใหญ่

## ปัญหาที่พบบ่อย

**กดเปิดแล้วขึ้นว่า "Windows protected your PC"**
กด **More info** แล้วกด **Run anyway** (ดูหัวข้อดาวน์โหลดด้านบน)

**แอนตี้ไวรัสบล็อกโปรแกรม**
แอนตี้ไวรัสบางตัวทักโปรแกรมที่สร้างจาก Python แบบนี้ แม้จะไม่มีอะไรอันตราย ถ้าโดนบล็อก ให้กดอนุญาต (Allow) ในแอนตี้ไวรัส
หรือใช้แบบรันจากโค้ดแทน (ดูหัวข้อสุดท้าย)

**ย้าย `MC-Perf-Mods.exe` ไปไว้ที่อื่นแล้วเปิดไม่ขึ้น**
ต้องวาง `MC-Perf-Mods.exe` ไว้คู่กับโฟลเดอร์ `_internal` เสมอ ถ้าอยากเปิดจากหน้าจอ ให้คลิกขวาที่ exe แล้วเลือกสร้าง Shortcut แทน

**ขึ้นว่า "ไม่พบไฟล์ข้อมูลม็อดแพ็ก"**
เลือกโฟลเดอร์ผิดชั้น ต้องเลือกโฟลเดอร์ของม็อดแพ็กที่มีโฟลเดอร์ `mods` อยู่ข้างใน ไม่ใช่โฟลเดอร์ `mods` เอง

**หน้าต่างดูเรียบๆ ไม่มีพื้นหลังขยับ**
เครื่องนั้นไม่มี Microsoft Edge WebView2 (มักเป็น Windows 10 รุ่นเก่าที่ไม่ได้อัปเดต) โปรแกรมเลยเปิดหน้าต่างแบบธรรมดาแทน
ใช้งานได้เหมือนกันทุกอย่าง ถ้าอยากได้แบบสวย ให้ลง [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) แล้วเปิดใหม่

**ลงแล้วเกมเปิดไม่ขึ้น**
เปิดโปรแกรม กด **ย้อนการติดตั้ง** เลือกรายการล่าสุด แล้วลองเปิดเกมใหม่

**CurseForge ไม่อัปเดตม็อดที่ลงด้วยโปรแกรมนี้**
เป็นเรื่องปกติ เพราะ CurseForge มองว่าเป็นไฟล์ที่ลงเอง ถ้าอยากได้รุ่นใหม่ ให้ย้อนการติดตั้งแล้วลงใหม่

## รันจากโค้ด (สำหรับคนที่มี Python)

ต้องมี Python 3 (ตอนติดตั้งติ๊ก "Add python.exe to PATH") แล้วดับเบิลคลิก **`เปิดโปรแกรม.bat`**
ครั้งแรกจะติดตั้ง pywebview ให้เอง ถ้าลงไม่ได้จะเปิดหน้าต่างแบบธรรมดาแทน

**สร้างไฟล์ zip สำหรับแจกเอง:** `python -m pip install pyinstaller pywebview pillow` แล้ว `python build_exe.py`
ได้ไฟล์ที่ `dist/MC-Perf-Mods.zip`

### แบบพิมพ์คำสั่ง

เปิด PowerShell ในโฟลเดอร์นี้ (ปิดเกมก่อน)

```
python scripts/perf.py plan     --instance "โฟลเดอร์ม็อดแพ็ก"            ดูก่อนว่าจะลงอะไร
python scripts/perf.py install  --instance "โฟลเดอร์ม็อดแพ็ก"            ลงจริง
python scripts/perf.py list     --instance "โฟลเดอร์ม็อดแพ็ก"            ดูประวัติการลง
python scripts/perf.py restore  --instance "โฟลเดอร์ม็อดแพ็ก" --install <ชื่อ>   ย้อนการติดตั้ง
python scripts/perf.py versions --loader forge                           ดูว่าเกมเวอร์ชันไหนมีม็อดครบ
```

ตัวเลือกเสริม

| ตัวเลือก | ใช้ทำอะไร |
|---|---|
| `--with jei,appleskin` | ลงม็อดสามัญประจำบ้านที่ระบุเพิ่ม (คั่นด้วยจุลภาค) |
| `--with-qol` | ลงม็อดสามัญประจำบ้านทั้งหมด |
| `--no-shaders` | ไม่ลง Iris / Oculus |
| `--no-essential` | ไม่ลง Essential |
| `--mc 1.21.1 --loader neoforge` | กำหนดเวอร์ชันเกมและ loader เอง |
| `--out <โฟลเดอร์>` | โหลดม็อดเก็บไว้ที่อื่น โดยไม่ลงในม็อดแพ็ก |
